# Dex documentation

One job: hold documentation while leaving source, runtime state and acceptance evidence
with their existing owners. Start at [handbook/index.md](handbook/index.md); its
[folder contract](handbook/CONTEXT.md) states inputs, process, outputs and human review.

The handbook explains setup/use, architecture, operations/troubleshooting and reference.
[handbook/status.md](handbook/status.md) distinguishes source inspection, dated claims
and runtime checks not performed. Do not copy secret or bulk payloads into this tree.
Generated human views are factory-owned snapshots of the canonical Markdown, never a
second hand-maintained requirements or approval ledger.
