# Handbook source and review contract

This handbook explains Dex's existing workflows and source-backed limits. Product code, cards and dated evidence keep their owners. The root `CONTEXT.md` owns runtime/evaluation/publication approval; these pages do not authorize those actions.

## Inputs and outputs

Canonical reader Markdown and `sidebar.json` live in this admitted handbook. Required source references identify reviewed repository paths/symbols, not public raw-source downloads. Private `docs/verification` contains the coverage map, exact author/reviewer snapshots and safe synthetic fixtures; it is not reader-site content.

Model weights/tokenizer bulk, retained benchmark rows/per-item answers, credentials/runtime state and previous generated HTML/PDF/receipt remain excluded. Do not copy them into pages or approved assets.

## Maintenance

A changed interface/source requires impact review, affected prose/examples/reference updates, native safe checks and fresh independent source/task review. Only exact accepted input bytes may enter the released shared site. Source/doc hashes detect drift; they cannot prove claims or model behavior.

The old four-page generated handbook views are retained history, not a parallel manually edited website. Shared-site integration, registry/toolchain and release belong to the parent owner. Start at [project landing](index.md), [collaboration](collaboration.md) or [current status](status.md).
